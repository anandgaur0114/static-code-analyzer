                        1
                        
Phase 1: Lexical Analysis (DFA Lexer)

                        
Scans raw characters and tokenizes keywords, identifiers, numeric literals, strings, and operators using a state machine with full line and column coordinate tracking.

                    

                    

                        2
                        
Phase 2: Syntax Analysis (LL(1) Parser)

                        
Implements recursive descent parsing with operator precedence climbing for expressions. Builds an Abstract Syntax Tree (AST) with panic-mode error recovery.

                    

                    

                        3
                        
Phase 3: Scoped Symbol Table

                        
Manages nested lexical scopes with a stack of hash tables. Handles variable declaration, shadowing, resolution, and detects unused variables on scope exit.

                    

                    

                        4
                        
Phase 4: Semantic Analysis & Dead Code

                        
Traverses AST to detect undeclared variables, variable redeclarations, and unreachable dead code following return, break, or continue statements.

                    

                    

                        5
                        
Phase 5: McCabe Cyclomatic Complexity

                        
Computes \(V(G) = P + 1\), where \(P\) counts decision points: if, while, for, and short-circuit operators &&, ||.

                    

                    

                        6
                        
Phase 6: Accuracy Scoring Engine

                        
Calculates quality score from a base of 100.0%, deducting penalties for syntax errors (-20%), undeclared variables (-15%), dead code (-8%), high complexity (-6%), and unused variables (-5%).
